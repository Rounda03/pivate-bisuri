일정비서 개인정보처리방침

시행일: 2026년 11월 9일

1. 수집하는 정보

  • 구글 계정 정보: 로그인에 쓰는 이메일 주소
  • 사용자가 허용한 경우, 폰에 도착한 메신저·문자 알림 내용과 통화 녹음 파일
  • 사용자가 허용한 경우, 폰 연락처의 이름·전화번호 (발신자 이름 표시용, 서버로 보내지 않음)
  • 사용자가 직접 입력한 회사·연락처·전략·메모

2. 이용 목적

  • 대화·통화 내용을 AI 로 요약해 사용자 본인의 영업 보고서를 만들기 위해
  • 보고서에서 찾은 일정을 사용자 본인의 구글 캘린더에 등록·조회하기 위해

3. 구글 사용자 데이터 (Google 캘린더)

앱은 사용자가 동의한 경우에만 구글 캘린더 일정 권한(calendar.events)을 사용하며, 사용자 본인의 캘린더에 일정을 등록하고 앱 화면에 일정을 보여 주는 데에만 씁니다. 캘린더 데이터를 광고에 쓰거나 다른 사람에게 판매·제공하지 않습니다.

앱이 Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 처리 위탁·외부 전송

  • Google Gemini API: 요약할 대화·녹음 내용을 보내 요약 결과를 받습니다.
  • Supabase: 보고서·전략 등 사용자 데이터를 보관합니다. 각 사용자는 본인의 데이터에만 접근할 수 있습니다.

위 목적 외에 제3자에게 개인정보를 제공하지 않습니다.

5. 보관과 삭제

앱이 폰에 모아 둔 대화 목록은 요약이 끝나면 앱에서 지웁니다(통화 녹음 원본 파일은 폰의 녹음 앱이 관리합니다). 보고서와 전략은 사용자가 앱에서 지울 수 있으며, 계정 데이터 전체 삭제를 원하면 아래 이메일로 요청하면 지체 없이 삭제합니다. 구글 계정 설정의 "타사 앱 액세스"에서 언제든 캘린더 권한을 취소할 수 있습니다.
